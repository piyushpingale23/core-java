# Java 16 Features

## 1. Records

- Records provide a concise way to create data carrier classes.
- The compiler generates a canonical constructor, getters methods, `toString()`, `equals()`, and `hashCode()`.
- Record components are final; records do not provide setters.
- No no-argument constructor is generated by default.

```
record Employee(int id, String name) {}

Employee employee = new Employee(101, "Piyush");

System.out.println(employee.id());   // 101
System.out.println(employee.name()); // Piyush
System.out.println(employee);        // Employee[id=101, name=Piyush]
```

## 2. Pattern Matching for `instanceof`

- Combines type checking and variable declaration.
- Eliminates the need for a separate explicit cast.

```
Object value = "Java";

if (value instanceof String text) {
    System.out.println(text.toUpperCase()); // JAVA
}
```

Traditional syntax:

```
if (value instanceof String) {
    String text = (String) value;
}
```

## 3. `Stream.toList()`

- Introduced in Java 16 to collect stream elements into a `List`.
- Returns an unmodifiable list.
- `Collectors.toList()` does not guarantee the mutability of its returned list.

```
import java.util.List;

List<String> names = List.of("Java", "Spring", "SQL");

List<String> result = names.stream()
        .filter(name -> name.length() > 3)
        .toList();

System.out.println(result); // [Spring]

// result.add("Python"); // UnsupportedOperationException
```

For a guaranteed modifiable list:

```
import java.util.ArrayList;

List<String> result = new ArrayList<>(
        names.stream()
             .filter(name -> name.length() > 3)
             .toList()
);

result.add("Python");
System.out.println(result); // [Spring, Python]
```

## Quick Revision

| Feature                           | Main benefit                                |
|-----------------------------------|---------------------------------------------|
| Records                           | Reduces boilerplate in data carrier classes |
| Pattern Matching for `instanceof` | Combines type checking and casting          |
| `Stream.toList()`                 | Concise stream-to-list conversion           |
